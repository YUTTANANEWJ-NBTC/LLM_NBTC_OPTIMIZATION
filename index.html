What to Remember When You Build This Yourself (4 Golden Rules + 2 Lessons)

01. Match the strategy to the wiring

เก็บ parallelism ที่พูดคุยกันเยอะ (expert routing, cache handoff) ไว้ภายใน NVLink domain เท่านั้น ระหว่างเครื่อง (RoCE/InfiniBand) ให้ส่งเฉพาะสิ่งที่เบา: pipeline activations หรือ whole requests

02. Disaggregation is a pattern, not a cluster size

P/D ทำงานได้แม้กระทั่งบนเครื่องเดี่ยว: 2 pools และ connector. เริ่มต้นทดสอบบนเครื่องเล็กก่อน ปรับจูน pool ตามคอขวดของมันเอง (Compute vs Memory-bandwidth)

03. The cache is still the product at 1M

แม้ CSA + HCA จะช่วยลดขนาดลง ~10× แต่หน่วยความจำที่เหลือยังเป็นหน้าที่ของคุณ: FP8 KV + block-size 256, FP4 indexer cache, และการจำกัด output tokens สำหรับ deep thinking

04. The flags ARE the architecture

ทุก deployment shape ถูกกำหนดด้วย flag ของ vllm serve เท่านั้น! โหลดน้ำหนักโมเดล 167 GB ครั้งเดียวลง Shared PVC (RWX) การเปลี่ยน shape เป็นเพียงแค่ 1 คำสั่ง kubectl apply

⚠️ Lesson from what went wrong: Benchmark performance AND outputs — fast junk is still junk! Pin the exact engine version: เวอร์ชัน vLLM ต่างกันความเร็วต่างกันถึง 45% และพบบั๊ก silent output บน TP4 ใน v0.27.1!
